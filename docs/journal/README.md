# Журнал действий агентов

Один файл на день: `<ГГГГ-ММ-ДД>.md`. Внутри — секции `## ЧЧ:ММ — <заголовок задачи>`.

Правила, обязательный минимум записи и шаблон — в скилле `docs-journal`
(`skills/docs-journal/SKILL.md`, рабочая копия для OpenCode — `.agents/skills/docs-journal/SKILL.md`).

## Помощник

```powershell
node scripts/journal.mjs stamp                 # метка "ГГГГ-ММ-ДД ЧЧ:ММ"
node scripts/journal.mjs start "<заголовок>"   # создать файл дня и секцию записи, вернуть путь
node scripts/journal.mjs list 5                # последние записи
node scripts/journal.mjs grep "<термин>"       # поиск по журналу
node scripts/journal.mjs read <ГГГГ-ММ-ДД>     # вывести запись дня
node scripts/journal.mjs path                  # путь к файлу сегодняшнего дня
```

## Что здесь искать

- Почему принято решение и что было отброшено — секции **Решения**.
- За что уже спотыкались — **Находки / риски** и **Блокеры**.
- Что проверялось и с каким результатом — **Проверки**.
- Крупные разборы лежат отдельно в `docs/*.md` (например `docs/V2_REFACTOR.md`), здесь — ссылки и выводы.
