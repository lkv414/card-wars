## Баги, найденные и исправленные
1. **Критический**: в `CardMesh.useFrame` `worldToLocal` применялся к базовой локальной позиции
   слота (нужно только к мировой точке драга) — карты с поля съезжали к центру стола
   (мировые позиции фиксировал через `__cwScene`). Исправлено (v5).
2. **Параллакс драга**: плоскость ловушки на y=45, стопка на y≈4 — луч из-под курсора мимо
   стопки на ~150 мм. Заменено на расчёт по лучу (tableY=1.6 + `overMyDiscardRay`) (v5).
3. Герои не копировались в dist (vite-плагин) — исправлено.
4. `CornerHint` рисовался с левой стороны (не по докам) — удалён.

## Как продолжать проверку UI (без сервера)
```
pnpm --filter @card-wars/client build
cd apps/client && npx vite preview --port 4173
# открыть http://localhost:4173/?scene=1  (мок-сцена + панель управления уроном)
```
Проверено визуально (v4): раскладка половин и делитель, сканы карт в руке/на поле/в сбросе,
портреты героев, жетоны урона 2×«1» и «3» на месте, падение и пересборка 1+1→3 с отскоками,
фрост на краю тайла, драг рука→зона (карта сыгралась). НЕ проверено: флюп-поворот, драг в
стопку (рука/поле), подсветка половин, отмена драга, мультиплеерные раскладки.
