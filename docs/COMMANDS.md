# Команды и события

Единый каталог действий игрока (команд) и порождаемых ими событий.

- Команды проверяет domain: незаконная команда отклоняется с причиной, законная — порождает события и новый снимок матча ([STRUCTURE.md](./STRUCTURE.md), «Ключевые контракты»).
- Этот же набор — основа сетевого протокола ([NETWORK.md](./NETWORK.md)).
- Документ фиксирует **состав** команд и событий; точные поля каждого — при старте кода.

## Команды

### Лобби

| Команда | Кто | Примечание |
|---|---|---|
| Создать лобби | любой | |
| Присоединиться по коду / ссылке | любой | 4-значный код |
| Выбрать / отредактировать колоду | участник | колода привязана к игроку; редактирование доступно и в лобби |
| Готов / не готов | участник | |
| Изменить режим (FFA 2–4 / 2 на 2, вариант расстановки) | хост | |
| Включить / выключить скрытие составов | хост | см. [NETWORK.md](./NETWORK.md) |
| Добавить / убрать бота | хост | |
| Пересадить игроков | хост | drag & drop |
| Запрос на обмен местами | участник | участник ↔ участник |
| Передать хоста | хост | если хост вышел — роль переходит следующему игроку |
| Кикнуть игрока | хост | |
| Начать матч | хост | когда все готовы |
| Покинуть лобби | любой | |

### Матч

| Команда | Когда законна (кратко) | Примечание |
|---|---|---|
| Муллиган | раз за партию, до первого хода | решение каждого игрока независимо; факт муллигана виден всем |
| Розыгрыш карты (существо / строение) | своя основная фаза; хватает действий и земель нужного типа | с выбором зоны; на замороженную землю — только после снятия мороза |
| Розыгрыш заклинания | своя основная фаза; хватает действий и земель нужного типа | эффект сразу, карта уходит в сброс |
| Розыгрыш / замена парной карты | своя основная фаза, режим 2 на 2 | в игре одна; при замене старая уходит в сброс |
| Замена карты в зоне | своя основная фаза | старая карта уходит в сброс |
| Перемещение карты | когда разрешено эффектом карты (`move`) | на свободную землю (свою или противника — по эффекту); действий не тратит, если не указано иное |
| Сброс карты с земли | своя основная фаза | |
| Сброс карты из руки | своя основная фаза | тот же механизм снимает мороз с земли |
| Флюп карты | своя основная фаза, до боя | платный флюп списывает действие; первый игрок в первый ход не флипает; в «стенке» первый круг — без флюпов |
| Добор дополнительной карты | своя основная фаза | 1 действие за карту |
| «В бой» | своя основная фаза | завершает её; в «стенке» бой команды начинается, когда нажали **оба** союзника |
| «Поторопить» | чужой ход | запуск / ускорение таймера |
| Сдаться | в любой момент | FFA — один игрок; в 2 на 2 должны сдаться **оба** игрока команды |
| Эмоция | после MVP | состав уточняется |

### Автоматические переходы (не команды игрока)

- Истечение таймера хода → автоматический переход в фазу боя ([RULES.md](./RULES.md), «Таймер хода»).
- Разрыв соединения → пауза и таймер ожидания возврата (60 секунд от первого оборвавшегося); не вернулся — партия завершается поражением обрывавшемуся ([NETWORK.md](./NETWORK.md)).

## События

Каждая применённая команда порождает события. События питают журнал, presentation (анимации, подсветки) и пересылаются по сети.

| Событие | Содержание (кратко) |
|---|---|
| Партия начата | состав, герои (в рамках видимости) |
| Ход начат / фаза изменена | игрок, фаза |
| Муллиган сделан | игрок (без раскрытия руки) |
| Карта добрана | кем (персональное событие — состав руки не раскрывается) |
| Карта сыграна | карта, зона, кем |
| Парная карта разыграна / заменена | карта, кем |
| Карта перемещена | карта, откуда — куда |
| Усиления изменены | цель, изменение бонусов атаки/хп |
| Карта заменена / сброшена | какая, откуда |
| Заклинание разыграно | карта, эффект |
| Флюп применён | карта, эффект, стоимость |
| Урон нанесён | цель, сколько, щит / хп |
| Существо уничтожено | карта, зона |
| Земля изменена | заморозка / снятие мороза / переворот |
| Жизни изменены | у кого, на сколько |
| Таймер запущен / ускорен / истёк | оставшееся время |
| Игрок выбыл / сдался | игрок |
| Партия завершена | победитель / команда; причина — в т.ч. обрыв соединения |

Формат строки журнала — [RULES.md](./RULES.md), «Журнал партии».
