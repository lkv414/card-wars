## Надёжность сервера

- Гибернация DO безопасна: сессии восстанавливаются из `deserializeAttachment`, боты и таймеры — через `alarm()`.
- При несовпадении `protocolVersion` клиент получает ошибку; PWA чистит кеш при отсутствующих чанках (`apps/server/src/index.ts`).
