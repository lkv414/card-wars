# AGENTS.md — Card Wars v3

Цифровая реализация настольной карточной игры Card Wars (Adventure Time), 2–4 игрока, онлайн в браузере, 3D-представление. Чистая переписывание (clean-room) по документации.

## Источник правды

- Вся игровая и техническая документация — в `docs/`, начни с `docs/README.md` (там карта документов).
- Ключевые: `docs/TECH.md` (стек и решения), `docs/RULES.md` (точные правила), `docs/COMMANDS.md` (команды/события), `docs/CARDS.md` (формат карт), `docs/UI.md` + `docs/UI-3D.md` (интерфейс и 3D).
- **Doc-first:** если чего-то не хватает — сначала дополняется документ, потом пишется код. Меняется правило — меняется документ, затем код.
- **Clean-room:** не подглядывать в `.archive/`, старые ветки и легаси ради структуры или решений.

## Технологический стек (кратко — детали в docs/TECH.md)

- TypeScript везде (strict). Монорепо: pnpm workspaces — `packages/{domain,application,protocol,content}` + `apps/{server,client}`.
- Сервер: Cloudflare Workers + Durable Objects (класс `Room`, SQLite write-through, alarms, WebSocket).
- Клиент: React + Vite + react-three-fiber (3D-игровое поле), DOM для меню/лобби/редактора колод.
- Синхронизация: полные персональные снапшоты (`viewFor(state, playerId)`) + события только для анимаций/журнала.
- Тесты: Vitest (+ fast-check), сидированный RNG. CI: GitHub Actions (lint + тесты domain).

## Конвенции (нарушать нельзя)

1. **domain — чистый**: ноль I/O, ноль ссылок на UI/сеть/БД; единственная зависимость — Immer. Никаких `Math.random` — RNG через порт, сид в состоянии матча.
2. **Никакого хардкода карт** и их эффектов: карты читаются только из данных (`packages/content`). Ссылка на конкретную карту в коде правил = ошибка.
3. **Константы правил — только из CONFIG** (значения из `docs/CONFIG.md`); констант-дублей в коде нет. Новый параметр правил → сначала строка в CONFIG.md.
4. **Скрытие информации**: чужая рука/колода не покидают сервер. Персональный вид строит только `viewFor`. События не содержат скрытых данных.
5. **UI тонкий**: presentation не решает законность действий, не мутирует состояние матча; анимации — только по событиям.
6. **Языки**: идентификаторы и комментарии в коде — английский; строки интерфейса и игровой контент — русский.
7. **zod только на границе** (адаптеры сервера/клиента), не внутри domain.

## Команды (по мере появления пакетов)

```
start.bat             # Windows: зависимости (при первом запуске) + сборка клиента + wrangler dev + браузер
pnpm install          # установка
pnpm -r test          # тесты (vitest)
pnpm -r build         # сборка пакетов → client → статика
wrangler dev          # локальный Worker + DO (из apps/server)
wrangler deploy       # деплой (из apps/server)
pnpm --filter @card-wars/server smoke        # e2e-смоук «двух вкладок» (нужен запущенный wrangler dev)
pnpm --filter @card-wars/server smoke:bots   # e2e-смоук 2 на 2 с серверными ботами
```

## Контент

- Каталог карт вшит в проект (`packages/content`); источник правды — папка [`content/`](content) (545 карт, 25 героев, земли; по JSON на сущность + картинки + `index.json`). Сборка каталога — `pnpm --filter @card-wars/content generate` (`tools/build-catalog.mjs`). Никаких ссылок на конкретные карты в коде правил.
- Пресеты колод MVP: герой **Бимо** и герой **Билли** (по колоде на каждого).
