# Общий конфиг проекта

Все настройки с настраиваемыми значениями собраны в **одном конфиг-файле** проекта. Здесь фиксируются **имена настроек и их базовые значения**; поменять значение можно в конфиге, не трогая правила.

---

## Правила работы с конфигом

1. Один конфиг на весь проект — никаких разбросанных констант по коду.
2. Настройка — это **число или перечисление, а не логика**: конфиг меняет параметры правил, но не сами правила.
3. Domain получает настройки через переданный конфиг (порт, как RNG и время — см. [STRUCTURE.md](./STRUCTURE.md)); значений по умолчанию внутри кода правил нет.
4. Новый параметр правил → сначала строка в этом документе, потом код.

## Настройки

### Партия

| Ключ | Базовое значение | Что задаёт |
|---|---|---|
| `startingLives` | 25 | стартовые жизни игрока (FFA) |
| `teamStartingLives` | 50 | стартовые жизни команды (2 на 2) |
| `maxLives` | = стартовые жизни | потолок лечения (25 / 50) |
| `deckSize` | 40 | размер колоды |
| `startingHandSize` | 5 | стартовая рука |
| `mulliganCount` | 1 | сколько раз доступен муллиган |
| `actionsPerTurn` | 2 | базовое число действий за ход (эффекты карт могут дать действия сверх этого значения) |
| `landsPerPlayer` | 4 | число тайлов земель у игрока (тип каждого — любой, дубликаты разрешены) |
| `freeDrawsPerTurn` | 1 | бесплатных доборов за ход |
| `extraDrawCost` | 1 | стоимость добора дополнительной карты (в действиях) |
| `companionMaxInPlay` | 1 | сколько парных карт может быть в игре у одного игрока |

### Колода

| Ключ | Базовое значение | Что задаёт |
|---|---|---|
| `copyLimit` | 4 | лимит копий одной карты (по умолчанию; точечные лимиты отдельных карт — переопределение в конфиге) |

### Таймеры

| Ключ | Базовое значение | Что задаёт |
|---|---|---|
| `turnTimerSeconds` | 90 | время хода после первого «Поторопить» |
| `hurrySpeedupFactor` | 2 | во сколько раз «Поторопить» ускоряет отсчёт |
| `hurrySpeedupWindowSeconds` | 1 | сколько длится окно ускорения (спам перезапускает его заново) |
| `reconnectWaitSeconds` | 60 | сколько ждать возврата оборвавшегося игрока |

### Лобби

| Ключ | Базовое значение | Что задаёт |
|---|---|---|
| `lobbyCodeDigits` | 4 | длина кода лобби |
| `minPlayers` | 2 | минимальное число игроков |
| `maxPlayers` | 4 | максимальное число игроков |
