# MVP — первая рабочая версия

## Цель MVP

Можно сесть и **сыграть полную партию** по базовым правилам локально (два человека за одним устройством или человек против очень простого бота).

---

## Входит в MVP

### Domain
- Модели: карта, игрок, зона, матч, фаза хода.
- Создание матча из двух заранее заданных колод.
- Муллиган (один раз).
- Полный цикл хода: подготовка → добор → действия/флюпы → нападение → конец хода.
- Розыгрыш существ, строений и заклинаний (базовые эффекты).
- Бой в зонах и урон по жизням.
- Уничтожение существ, замена.
- Определение победителя (0 жизней).
- Базовый набор карт (достаточно для интересной партии, не обязательно все оригинальные).

### Способ «поиграть»
- Любой минимальный интерфейс:
  - текстовый / CLI, или
  - очень простой 2D UI.
- Должно быть видно: поле, руки, жизни, текущую фазу, доступные действия.

### Тесты
- Unit-тесты на domain (создание игры, розыгрыш, бой, победа, ключевые edge-cases).

---

## Не входит в MVP

- Сеть / онлайн-матчи
- 3D-доска
- Редактор колод и библиотека карт с красивым UI
- Админ-панель
- Аккаунты, прогресс, рейтинг
- Реплеи и сохранение истории (можно добавить сразу после MVP)
- Полный набор всех карт и всех редких взаимодействий оригинала
- Красивые анимации и полировка UX

---

## Критерий готовности MVP

> Два игрока (или игрок + бот) могут начать матч, провести несколько ходов с розыгрышем карт и боем и закончить игру победой одного из них, при этом все действия проверяются domain-слоем и покрыты тестами.

После этого можно наращивать контент, UI и мультиплеер, не ломая ядро.
