# Дизайн-спецификация: Унификация UI лобби, редактора колод и меню (Ooo Tabletop Grimoire)

**Проект:** Card Wars v3  
**Целевые экраны:**
1. **Лобби комнаты (`/play/<code>`):** `apps/client/src/game/lobby/Lobby.tsx`
2. **Список колод (`/decks`):** `apps/client/src/decks/DecksScreen.tsx`
3. **Редактор колод (Grimoire):** `apps/client/src/decks/DeckEditor.tsx`
4. **Главное меню и Никнейм:** `apps/client/src/App.tsx`
5. **Глобальные стили:** `apps/client/src/styles.css`

---

## 1. Концепция и дизайн-система

Интерфейс всех 2D-экранов переводится на единый визуальный стандарт, утвержденный в `docs/AUDIT-KIBERBUS-UIUX.md`:
* **Типографика:** `font-family: 'Balsamiq Sans', cursive, sans-serif` для всех заголовков, кнопок, бейджей, цифр и названий.
* **Тактильные 3D-кнопки Balatro (`.cw-btn-3d`):**
  - Скос тени 7 px (`box-shadow: 0 7px 0 var(--btn-shadow)`).
  - Смещение при нажатии `translateY(5px)` с уменьшением тени до `0 2px 0`.
  - Цветовая семантика:
    - **Зеленый (`btn-green`):** Готовность, Выбор колоды, Сохранение («В бой! (Готов)», «Сохранить», «Выбрать»).
    - **Красный (`btn-red`):** Старт матча, Удаление, Очистка («⚔️ Начать матч!», «Удалить», «Очистить»).
    - **Синий (`btn-blue`):** Обзор, Редактирование, Копия («👁 Обзор», «Редактировать», «Копия»).
    - **Оранжевый (`btn-orange`):** Случайная генерация, Пересадка («🎲 + Случайная колода», «🎲 Случайный набор», «⇅ Пересадить»).
    - **Фиолетовый (`btn-purple`):** Код колоды, Настройки («Код», «Настройки»).
    - **Темный/Деревянный (`btn-dark`):** Навигация назад, Отмена («← Выйти из лобби», «← В меню», «Отмена»).
* **Крафтовые контейнеры (`.cw-felt-box`, `.cw-paper-box`):**
  - Подложки со скруглением 16–20 px, темным чернильным кантом `#3b2921` и внутренней пунктирной строчкой цвета шалфея.

## 2. Спецификация изменений по экранам

### 2.1. Лобби стола (`Lobby.tsx`)
- Кнопка выхода: `.cw-btn-3d.btn-dark.btn-sm` («← Выйти из лобби»).
- Блок кода комнаты: оформление в виде крафтового свитка с латунной кнопкой копирования.
- Селектор колоды: кастомный деревянный селект с золотым шевроном + кнопки `.cw-btn-3d.btn-blue.btn-sm` («👁 Обзор») и `.cw-btn-3d.btn-green.btn-sm` («Редактировать»).
- Арена стола: контейнер `.cw-felt-box` с имитацией сукна коврика.
- Карточки слотов игроков: бейджи статуса («🛡️ ГОТОВ» / «⏳ ЖДЁТ»), кнопки управления ботами и пересадкой на кнопках `.cw-btn-3d`.
- Кнопка готовности: крупная кнопка `.cw-btn-3d.btn-green.btn-lg` («В бой! (Готов)» / «✓ Вы готовы»).
- Кнопка старта для хоста: пульсирующая `.cw-btn-3d.btn-red.btn-xl` («⚔️ Начать матч!»).

### 2.2. Список колод (`DecksScreen.tsx`)
- Шапка: кнопка возврата `.cw-btn-3d.btn-dark`, действия: `.cw-btn-3d.btn-orange` («🎲 + Случайная колода») и `.cw-btn-3d.btn-green` («+ Создать колоду»).
- Карточки колод: темные деревянные плашки с латунным кантом, действия над колодой:
  - «Выбрать» / «Выбрана»: `.cw-btn-3d.btn-green.btn-sm`
  - «Изменить»: `.cw-btn-3d.btn-blue.btn-sm`
  - «Код»: `.cw-btn-3d.btn-purple.btn-sm`
  - «Копия»: `.cw-btn-3d.btn-blue.btn-sm`
  - «Удалить»: `.cw-btn-3d.btn-red.btn-sm`
- Модальное окно удаления: диалог в стиле `.cw-paper-box` с кнопками подтверждения.

### 2.3. Редактор колод (`DeckEditor.tsx`)
- Шапка: кнопка выхода `.cw-btn-3d.btn-dark.btn-sm`, закладки земель в стиле латунных ярлыков.
- Действия с колодой в правой колонке:
  - «Очистить»: `.cw-btn-3d.btn-red.btn-sm`
  - «🎲 Случайный набор»: `.cw-btn-3d.btn-orange.btn-sm`
  - «Сохранить»: `.cw-btn-3d.btn-green.btn-sm`
- Кнопки добавления/удаления копий в списке: объемные круглые кнопки `[-]` и `[+]`.
- Фильтры типов и земель в левой колонке: оформление в виде тактильных плашек Balatro.

### 2.4. Главное меню (`App.tsx`)
- Карточка готовой колоды: тактильная плашка со строчкой нитками и кнопкой «📜 Открыть».
- Поле ввода ника и кнопка «⚔️ Создать битву»: массивная `.cw-btn-3d.btn-green.btn-lg`.
- Ввод кода комнаты и кнопка «Войти»: `.cw-btn-3d.btn-orange`.
- Кнопка «📖 Гримуар колод (Каталог)»: `.cw-btn-3d.btn-blue.btn-lg`.
- Нижние переключатели настроек (звук, музыка, графика): компактные `.cw-btn-3d.btn-dark.btn-sm`.
