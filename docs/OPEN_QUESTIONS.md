## Неструктурированные карты — нужны оригиналы/решения (2026-11-07)

5 карт остались без механик: текст OCR нечитаем или реализация требует переделки схемы. Ждут сверки с оригиналом карт / решения владельца:

| Карта | Текст OCR | Проблема |
|-------|-----------|----------|
| cake_card_18 Крепкий лесоруб | «Можешь сыграть дополнительное строение на этой земле» | второй слот строения на земле — изменение схемы зон + view + клиента |
| cake_card_33 (Крысолов) | «Когда Крысолов атакует…, можешь атаковать примененным существом… вместо него» | подмена атакующего требует решения ВНУТРИ обмена урона (см. §H14) |
| charlie_card_33 Вязаный котенок | «На Вязаного котенка действуют строения соседних земель» | наследование игровых текстов строений — динамическое копирование способностей |
| fiona_card_31 Центр знаний | «получает игровой текст строений… на соседних линиях (но не их имена)» | то же наследование текстов |
| ftg_card_67 | «Смени до 2х своих земель с теми которые сейчас не в игре» | в состоянии нет резерва земель вне игры — нужна концепция резерва в RULES |

Плюс jake_2v2_card_28 (текст-мусор OCR) реализован по лучшей трактовке: атакующее существо владельца покидает игру перед уроном — сверить с оригиналом.
