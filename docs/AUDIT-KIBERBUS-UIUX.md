## 1. Executive Summary & Главные архитектурные уроки

Порт от `kiberbus` — один из наиболее визуально зрелых и аутентичных проектов по мотивам *Adventure Time: Card Wars*. В отличие от сухих цифровых ККИ (где интерфейс часто выглядит как минималистичные серые панели с плоскими иконками), проект `kiberbus` строго выдерживает атмосферу мультсериала и ощущение настоящей физической настольной игры:

1. **Диегетический мир (Diegetic Tabletop):** Игра разворачивается на деревянном столе Финна и Джейка с разбросанными предметами пикника из мультсериала: сэндвич с салатом и беконом, жестяная банка Total Soda, пачка чипсов Crunch Chips, кружка Cool Guy, розовая чашка с ложкой, улитка с машущей лапкой (пасхалка сериала), гантель и карманные часы. Все предметы органично вписаны в растровую подложку коврика `playmat.webp` (1800×1263 px) и процедурную столешницу `WoodUI.table()`.
2. **Эстетика Balatro + Крафтовый сторибук:** Интерфейс сочетает сочные, тактильные, псевдо-3D «пластиковые» кнопки в духе Balatro (с яркими цветами, черными контурами и 7-пиксельным нижним скосом тени, физически сжимающимся при нажатии) и крафтовые элементы из цветной бумаги и фетра: неровные рваные контуры с математическим гармоническим дрожанием (harmonic wobble), стежки белыми нитками по канве, кусочки полупрозрачного скотча, приклеенные под углом бумажные ярлыки.
3. **Шрифтовая дисциплина:** Игра использует шрифт **Balsamiq Sans** (рукописный, мультяшный, неровный), обведенный жирным темным контуром цвета чернил (`#3b2921`) с мягкой тенью и специальной вертикальной микрокомпенсацией глифов кириллицы (чтобы хвостики букв «р», «у», «д», «ц», «й» не обрезались).
4. **Умный HUD без лишних кликов:** Слева от игрового поля постоянно отображается крупное превью (490×686 px) карты, на которую наведен курсор. Игроку не нужно зажимать правую кнопку мыши или открывать модальное окно, чтобы прочитать полный текст карты. Вся ключевая боевая информация вынесена в правый сайдбар: крупные сердца здоровья (68 px), стек действий из тактильных круглых жетонов-монет с маркерами модификаторов, яркие кнопки фаз и компактный автоскроллящийся лог боя.
5. **Мобильная адаптация первого класса:** Архитектура `phone.gd` и `touch_input.gd` исключает «слепые клики» и мелкие кнопки: минимальный тач-таргет равен 58–116 px (физические 7–8 мм под палец), удержание пальца 450 мс с виброоткликом эмулирует правый клик для зума, списки скроллятся без ложных срабатываний тапов, а декбилдер автоматически трансформируется из 3-колоночного в адаптивный режим.

## 2. Разбор и коррекция ключевых фактов реализации

| Элемент | Первое поверхностное впечатление | Что на самом деле в коде Godot 4 | Архитектурный вывод для Card Wars v3 |
|---|---|---|---|
| **Предметы на столе (пропсы)** | Отдельные 2D/3D спрайты с коллизиями вокруг поля | Код `board.gd` загружает единый текстурный коврик `playmat.webp` (1800×1263 px). Все предметы (содовая, чипсы, сэндвич, улитка) нарисованы прямо на нем. | В 3D-сцене Three.js выгоднее всего использовать качественную PBR-текстуру коврика или единый атлас, не создавая сотни лишних полигонов для каждого стакана. |
| **Деревянный стол** | Статичная текстура или заливка цветом | `wood_ui.gd` (`WoodUI.table()`): процедурный холст. Доски высотой 118 px, 3 чередующихся тона `PLANKS`, световая фаска шва `SEAM`, волокна по синусоиде, овальные сучки `draw_arc` и радиальная виньетка. | В Three.js делаем процедурный шейдер дерева для плоскости стола или запеченную бесшовную текстуру досок с нормалями. |
| **Фоновые пейзажи** | Статичный рисунок горы в меню | `backdrop.gd`: менеджер 7 фонов Земель Ууу (`tree_fort`, `daisies`, `giant_tree`, `moon_lake`, `starry_night`, `fireflies`, `earth`). Таймер 16 с, кросс-фейд 2.5 с, предзагрузка в потоке. | Внедрить менеджер пейзажей с плавной сменой времени суток/локаций на фоне 3D стола и выбор фона в настройках. |
| **Четкость текста карт** | Стандартное сжатие текстур | `sharp.gdshader`: отрисовка карт через `texture(TEXTURE, UV, -0.5)` (отрицательный bias мипмапов) + Lanczos-фильтрация. | В Three.js выставить `texture.anisotropy = renderer.capabilities.getMaxAnisotropy()` и `texture.minFilter = THREE.LinearMipmapLinearFilter`. |
| **Фильтр «Под мои земли»** | Сравнение с массивом выбранных типов | `deck_builder.gd` (`_payable`): `int(d["cost"]) <= have`. Учитывается не только тип земли, но и **число выставленных земель** (карта за 3 Болота скрывается, если у игрока только 2 Болота). Карты за 0 маны требуют минимум 1 землю своего типа. | Реализовать в нашем React-декбилдере строгий фильтр `isCardPayable(card, activeLands)`. |
| **Звуки интерфейса** | 2 стандартных пресета | `sfx.gd`: выбор из 17 звуков клика (bubble, kalimba, wood, thock, bmo, crystal и др.). Реплики героев при 12 боевых событиях (start, floop, attack, hurt, win и др.). Случайный питч $\pm 60$ центов. | Добавить в `SoundEngine.ts` рандомизацию частоты и тактильные банки щелчков. |
| **Цветовая адаптация к столу** | Один и тот же яркий цвет везде | `wood_ui.gd` (`tone()`): формула сжатия насыщенности $\times 0.72$ и яркости $\le 0.82$. Яркие неоновые цвета UI смягчаются до благородных пастельных оттенков бумаги на столе. | Использовать двухуровневую дизайн-систему: чистый `CW_UI_KIT` для HUD/кнопок и приглушенный `CW_WOOD_UI` для игрового поля. |

## 3. Детальный разбор 4 основных экранов (по скриншотам 1920×1080)

* **Логотип:** Трехмерный объемный шрифт в стиле заставки мультсериала (градиент канареечно-желтый $\to$ янтарный), жирный контур чернил `#3b2921`, падающая тень и корона над «Й».
* **Контейнер меню (`paper_box`):** Оливково-зеленый фетровый плакат со скруглением углов 22 px, обстроченный по внутреннему периметру пунктирной нитью цвета шалфея (`#b3cca3`).
* **Тактильные кнопки (Balatro Buttons):** 4 массивные кнопки высотой 64 px с 7-пиксельным скосом псевдо-3D тени:

  - «Настройки» — мягкий фиолетовый (`#8054bf`);

Функция тональной компрессии (`tone`):
$$\text{Color}_{\text{table}} = \text{HSV}(H, S \times 0.72, \min(V, 0.82))$$

### 4.2. Механика 3D-кнопок Balatro
1. **Покой:** Скругление 14 px. Тень: `0 7px 0 color.darkened(0.55)`.
2. **Ховер:** Цвет осветляется на 15%: `color.lightened(0.15)`. Звук `sfx("click")`.
3. **Клик:** Цвет темнеет на 10%: `color.darkened(0.10)`. Тень сплющивается до `0 2px 0`. Сдвиг содержимого вниз на 5 px (`translateY(5px)`). Звук `sfx("press")`.

### 4.3. Алгоритм неровных крафтовых рамок (`paper_box.gd`)
Вершины контура вычисляются интерференцией двух гармоник:
$$\Delta r(t, \text{seed}) = \text{wobble} \cdot \left( 0.6 \cdot \sin\left(\frac{t}{37.0} + 1.618 \cdot \text{seed}\right) + 0.4 \cdot \sin\left(2.37 \cdot \frac{t}{37.0} + \text{seed}\right) \right)$$
- Контур делится на шаги по 22 px. Каждая точка смещается по нормали на $\Delta r$.
- Передача `seed = hash(text) % 97` обеспечивает стабильную, но индивидуальную «ручную» неровность для каждого элемента.
- Внутри контура с отступом 9 px прорисовывается строчка нитками (`_dashes`): штрих 9 px, пробел 7 px, толщина 2 px.

### 4.4. Типографическая микрокомпенсация глифов (`wood_ui.gd`)
- Шрифты: **Balsamiq Sans Bold** (интерфейс, цифры, кнопки) и **Balsamiq Sans Regular** (тексты, описания).
- Обводка текста: толщина $\max(4, \text{round}(px \times 0.22))$, цвет `INK` (`#3b2921`).
- Вертикальная компенсация для кириллицы:
  $$\text{spacing\_top} = \lceil \text{fontSize} \times 0.06 \rceil, \quad \text{spacing\_bottom} = \lceil \text{fontSize} \times 0.20 \rceil$$
- Компенсация заглавных букв: сдвиг текста вниз на $\text{low} = \text{round}((\text{fontSize} - 17) \times 0.18)$ px.

## 5. Шейдеры и графические эффекты

### 5.1. Псевдо-3D шейдер карты (`shaders/card.gdshader`)
```glsl
// Перспективный наклон (Tilt)
vec2 want = Vector2(mouse_y * 16.0, -mouse_x * 20.0);
vec2 idle_tilt = vec2(sin(1.3 * TIME + seed) * 2.5, cos(1.05 * TIME + seed) * 3.5);

// Скользящий световой блик (Specular Sheen Band)
float band_pos = y_rot / 40.0 - x_rot / 60.0;
float d = (st.x * 0.8 + st.y * 0.6) - 0.7 - band_pos;
float band = exp(-d * d * 60.0) * 0.22 + exp(-d * d * 900.0) * 0.18;
col.rgb += vec3(band) * sheen;

// Радужная голография (Rainbow Foil)
if (foil > 0.0) {
    float lum = dot(col.rgb, vec3(0.299, 0.587, 0.114));
    vec3 rainbow = hue(fract(st.x * 0.9 + st.y * 0.6 + y_rot / 90.0 + x_rot / 120.0 + TIME * 0.05));
    float mask = smoothstep(0.35, 0.95, lum) * 0.35 + 0.08;
    col.rgb = mix(col.rgb, col.rgb * 0.6 + rainbow * 0.7, foil * mask);
}
```

### 5.2. Шейдер супер-резкости (`shaders/sharp.gdshader`)
Исключает замыливание текста на микро-картах:
```glsl
COLOR = texture(TEXTURE, UV, -0.5) * v_color;
```

## 6. Звуковая система и реплики героев (`sfx.gd`)

1. **Два звуковых банка:**
   - `CW_BANK` («Мультик»): аутентичные оцифрованные сэмплы из оригинальной мобильной игры Cartoon Network (`cw/card_move`, `cw/floop`, `cw/attack`, `cw/hit`, `cw/crit`, `cw/derez`, `cw/spell`, `cw/leader` и др.).
   - `BANK` («Обычные»): живая фоли-запись: шелест плотной бумаги, раскладка веера, глухой стук деревянных фишек.
2. **17 звуков клика кнопок:** переключаемый список (bubble, kalimba, wood, thock, bmo, crystal и др.).
3. **Реплики героев в бою (`hero_voice`):** 12 боевых триггеров (`start`, `turn`, `floop`, `attack`, `kill`, `hurt`, `win`, `lose`), интервал `VOICE_GAP = 3.5 с`.
4. **Защита от усталости слуха:** случайная расстройка высоты тона (`pitch_variance = ±0.04..0.08`), минимальный интервал повтора `MIN_GAP = 0.045 с`.

   export function isCardPayable(card: { cost: number; landType: string }, activeLands: string[]): boolean {
