# Глоссарий: термины оригинала → термины v3

Тексты карт берутся из оригинальной настольной игры **дословно**, поэтому в них встречается терминология оригинала. При реализации механик термины сопоставляются по этой таблице.

---

| В текстах карт (оригинал) | Термин v3 | Пояснение |
|---|---|---|
| «ПРИЁМ» | **Флюп** | активная способность: повернуть карту и применить эффект |
| Линия | **Зона** | у каждого игрока 4 зоны; «на этой линии» = в этой зоне |
| Соседние линии | **Соседние зоны** | зоны того же игрока слева / справа от данной |
| «Вступает в игру» | **Розыгрыш карты** | карта выкладывается из руки на поле |
| «Применённое / подготовленное существо» | **Готовое существо** | не флипнутое, обязано нападать |
| «Переверни карту» (состояние) | **Флип** | карта повёрнута — флюп уже использован |
| Стопка сброса | **Сброс** | |
| Радужная (rainbow) | **Радужная** (`rainbow`) | подходит любой тип земель; в данных v1 обозначена `any` — заменяется при новом OCR |
| corn / blue / good / ice / sand / swamp | Типы земель | кукурузные, синие, добрые, льдистые, песчаные, болотистые |
| «Существо под твоим контролем» | **Своё существо** | |

---

Правило чтения текстов: механика реализуется по смыслу в терминах v3. Артефакты OCR в текстах игнорируются до нового OCR (см. [MECHANICS.md](./MECHANICS.md), «Заметные закономерности»).
