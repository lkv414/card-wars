# Three.js Camera — Card Wars v3

Руководство по настройке и анимации камеры в 3D-сцене карточной игры на **React Three Fiber** в соответствии со спецификацией [docs/UI-3D.md](../../docs/UI-3D.md) и скиллом [r3f-best-practices](../r3f-best-practices/SKILL.md).

---

## 1. Базовые параметры камеры

* **Тип камеры:** `PerspectiveCamera` (перспектива передаёт глубину стола и наклон лежащих карт).
* **Якорь (LookAt):** Центр стола `(0, 0, 0)` всегда является целевой точкой взгляда.
* **Плоскости отсечения:**
  - `near: 1` — позволяет приближать карты при детальном осмотре без срезания геометрии.
  - `far: 2000` — достаточно для охвата стола и мягкого фона комнаты без потери точности z-буфера.
* **FOV (Угол обзора):** Базовый `45°`–`50°`. На узких мобильных экранах (портретная ориентация) динамически масштабируется по формуле от соотношения сторон `aspect`, чтобы весь стол оставался в кадре без бокового обрезания.

## 2. Режимы камеры ([UI-3D.md](../../docs/UI-3D.md) § «Камера»)

Переключатель режимов находится в верхней панели HUD и сохраняется в `localStorage`:

### 1. «За ходом» (`follow`, по умолчанию)
- При смене активного игрока камера плавно вращается по кругу вокруг центрального якоря стола к стороне игрока, чей сейчас ход (в 2 на 2 — к стороне активной команды; если моя команда активна — к моей стороне).
- **Кривая анимации:**
  - Плавный старт (ускорение).
  - Резкое торможение у цели.
  - Лёгкий инерционный откат назад (**overshoot**), создающий физическую тактильность.

### 2. «Своя сторона» (`self`)
- Камера возвращается и фиксируется на базовом ракурсе со стороны самого игрока (мой ряд всегда снизу экрана).

## 3. Высота и дистанция по режимам игры

В зависимости от числа игроков и геометрии стола базовая дистанция камеры меняется:

| Режим стола | Геометрия | Высота $Y$ | Дистанция $Z$ | Особенности |
|---|---|---|---|---|
| **1 на 1** | 2 ряда по 4 зоны вплотную | Базовая (~180–220) | ~260–300 | Классический вид на два встречных ряда |
| **FFA 3 игрока** | Треугольник | Приподнята (+25%) | Отодвинута (+30%) | Все 3 доски вписаны в конус видимости |
| **FFA 4 игрока** | Квадрат | Приподнята (+35%) | Отодвинута (+40%) | Все 4 доски вписаны в конус видимости |
| **2v2 «Стенка»** | 2 ряда по 8 зон | Приподнята (+30%) | Отодвинута (+50%) | Широкий фронт стола |

При выбывании игрока в FFA стол плавно перестраивается (квадрат → треугольник → 2 линии), и позиция камеры интерполируется новой высотой и дистанцией.

## 4. Реализация в R3F без потери кадров

- Позиция камеры в `useFrame` интерполируется через `MathUtils.lerp` или сферические координаты `slerp`.
- **Никаких вызовов `setState`** для обновления координат камеры!
- В режиме `frameloop="demand"` пока камера находится в движении, вызывается `invalidate()`:

```tsx
useFrame((state, delta) => {
  if (isAnimating) {
    // Интерполяция вектора позиции камеры
    camera.position.lerp(targetPos, 1 - Math.exp(-speed * delta));
    camera.lookAt(0, 0, 0);
    state.invalidate();
    if (camera.position.distanceTo(targetPos) < 0.1) {
      isAnimating = false;
    }
  }
});
```
