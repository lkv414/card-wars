# Аудит 3D-сцены

Файлы: `apps/client/src/game/scene/` (≈5,8 тыс. строк, без тестов ≈4,3 тыс.).

## Конфигурация `Canvas` (`Scene.tsx`)

| Параметр | Значение |
|----------|----------|
| `frameloop` | `"demand"` |
| `dpr` | `[1, 1.5]` при `quality='high'`, иначе `1` |
| `shadows` | только при `quality='high'` |
| Камера | собственный `CameraRig` (сферические координаты, `cameraSnap.ts`, `cameraTrauma.ts`), без `@react-three/drei` |

## Render loop

- `useFrame` используется в `AnimLayer` (5), `BackdropManager`, `CardMesh`, `DamagePile`, `Hand` (3), `Scene` (2).
- Хуки, которые анимируют, вызывают `invalidate()` только пока идёт движение (например `DamagePile.tsx:244`, `Scene.tsx:461–468` — `if (busy) invalidate()`), то есть в покое кадры не рисуются.
- Загрузка сканов будит кадр через `subscribeImageLoads` (`Scene.tsx:65`).

## Raycast и ввод

- `NO_RAYCAST` применяется в 41 месте сцены: декоративные меши исключены из лучей.
- ПКМ по карте открывает `CardZoomModal`, ЛКМ-удержание 360 мс — флюп; камера — свайп/колесо/WASD.
- Коврик квадратный и адаптивный, чтобы все земли и аксессуары помещались на столе.
