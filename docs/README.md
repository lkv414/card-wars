# Card Wars v3 — Documentation

Эта ветка содержит **только документацию** для переписывания проекта с нуля (clean-room).

Цель: описать игру и архитектуру так, чтобы реализация по этим документам **не повторяла** текущую структуру кодовой базы.

## Принцип работы с документацией

1. Документация — источник правды.
2. Код пишется **только** после утверждения соответствующих разделов.
3. При реализации нельзя «подглядывать» в старые ветки ради структуры или решений.
4. Если чего-то не хватает в документации — сначала дополняем документ, потом пишем код.
5. Выбор технологий обсуждается отдельно и **не фиксируется** в этих документах.
