# 2026-09-02

## Аудит производительности 3D-поля (card_game)

Провёл глубокий анализ `src/components/Game/**` (GameBoard3D, scene/*, gameBoard3D/*),
утилит (textureCache, useCardTexture, cardSceneHelpers, sceneHelpers, gameObjectPlacement),
стора, WS-транспорта, vite.config, dist/, скиллов.

Отчёт: `docs/PERFORMANCE_AUDIT_3D.md` (создан).

Ключевые цифры (2 игрока, полное поле):
- **182 draw call'а**, ~1.5 K треугольников, ~97 прозрачных quad'ов.
- **58 инстансов troika `<Text>`** (4 на существо, 3 на строение) — самая дорогая часть.
- VRAM 150–220 МБ; art карт 797×1104 PNG → ~4.7 МБ/карта с мипмапами.
- Бандл: three-vendor 1.08 MB + index 543 KB (≈430–480 KB gzip).

Главные находки (приоритет на исправление):
1. `<Environment preset="city">` тянет `potsdamer_platz_1k.hdr` (~1.7 МБ) с
   `https://raw.githack.com/pmndrs/drei-assets/...` через `useLoader` → Suspend
   `<Suspense fallback={null}>` в GameCanvas размонтирует ВСЮ сцену на время загрузки.
2. `directionalLight castShadow` — но во всём `src/` нет ни одного `castShadow` на меше.
   Тени включены, но ничего их не отбрасывает: shadow pass + 1024² depth + USE_SHADOWMAP.
3. `frameloop` не задан → "always": 60 fps при статичном кадре.
4. `memo(GameLand)` / `memo(GameObject)` не работают — в рендере GameBoard3D каждый раз
   создаются новые замыкания, массивы position/rotation и `resolveCardVisual()` (spread).
5. Утечка: `textureCache` без LRU, `clearTextureCache()` нигде не вызывается.

Найденные баги (мёртвый код / нестыковки):
- `<GameLand onClick={...}>` — GameLand деструктурирует `onLandClick`, `LandMat` не
  объявляет `onClick` вообще → клик по земле и `handleLandClick` мертвы.
- `slotRegistry.registerPlayableSlot` нигде не вызывается → `placementRaycast` делает
  полный `scene.traverse()` на каждый `pointerup`.
- `utils/sceneHelpers.js` полностью мёртв (только свои тесты).
- `gameBoard3D/layout.js` — полный дубль `utils/gameObjectPlacement.js`.
- `damageFlash` оставляет карту со сдвигом после окончания (useFrame пишет position.x/z,
  useEffect на снятие флага не перезапускается).
- `textureCache.js`: `loader.setCrossOrigin()` вызывается ПОСЛЕ `loader.load()`.
- `updatePointer` вызывает `getBoundingClientRect()` на каждый pointermove.
- `<color attach="background">` перекрывает CSS-градиент из GameCanvas (мёртвый стиль).
- fog near=18 при дистанции камеры ~8–13 → поле не затуманено, но USE_FOG компилируется.

Проверено в R3F (events-b389eeca.esm.js):
- `args` сравниваются shallow (`:15354`) → геометрии при ре-рендере НЕ пересоздаются.
- `is.equ` по умолчанию `{arrays:'shallow', objects:'reference'}` → объектные пропсы
  (например `userData={{...}}` в SlotPad) переприменяются каждый рендер.
- `gl={{...}}` — новый объект каждый рендер → `applyProps(gl, ...)` на каждом рендере.
