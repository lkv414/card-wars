# Карты и каталог

Этот документ описывает **единый формат данных карты** и подход к каталогу карт.
Визуальный формат карты (ячейки урона/хп/щита/бонусов) — в [UI.md](./UI.md), «Формат карты».

---

## Формат данных карты

Карта описывается **данными**; логика эффектов — отдельно (см. ARCHITECTURE.md, «Карты и эффекты»). Примеры JSON-карт (существо с пассивкой, платный флюп, строение с аурой) готовятся после завершения документации.

Поля (имена нейтральные, без привязки к языку/стеку):

| Поле            | Для каких карт | Содержание |
|-----------------|----------------|------------|
| `id`            | всех           | Уникальный идентификатор карты |
| `name`          | всех           | Название |
| `type`          | всех           | `creature` (существо) / `building` (строение) / `spell` (заклинание) / `companion` (парная) |
| `cost`          | всех           | Стоимость в действиях: 0, 1, … |
| `landType`      | всех           | Требуемый тип земли или `rainbow` (радужная — любой тип) |
| `attack`        | существ        | Базовая атака |
| `defense`       | существ        | Базовое хп |
| `image`         | всех           | Изображение для карты |
| `description`   | всех           | Игровой текст (нижняя часть карты) |
| `abilities`     | всех (может быть пусто) | Список способностей — см. ниже |
| `deckSet`       | всех           | Набор оригинальной игры, из которого карта |

### Структура способности

| Поле         | Содержание |
|--------------|------------|
| `kind`       | `passive` (пассивная) / `floop` (активная) |
| `floopCost`  | только для `floop`: 0 (бесплатный) или 1 действие |
| `trigger`    | для пассивных: `constant` (постоянная) / `on_enters_play` / `on_death` / `on_damage_dealt` / … — имена триггеров каноничны по [MECHANICS.md](./MECHANICS.md) |
| `effect`     | операция или ссылка на именованный обработчик (см. ARCHITECTURE.md) |
| `text`       | формулировка способности для отображения |

### Отдельные механики
- **Щит** — задаётся только способностью (пассивной или Флюпом), которая его даёт. Отдельного поля у карты нет.
- **Парная карта** — бонус направлен союзнику; работает только в режиме 2 на 2 (скрыта в редакторе колод по умолчанию). Активный бонус (Флюп) активирует владелец карты. В игре может находиться **только одна**; в колоде может быть несколько копий — для замены в процессе. Способности парных карт в текущем каталоге **не структурированы** (текст остаётся в `description`, как и у остальных карт до нового OCR): карта разыгрывается и заменяется как объект.

## Герои

Герой — **отдельная сущность**, не карта. Каждый игрок выбирает героя в редакторе колод перед партией.

Поля:

| Поле        | Содержание |
|-------------|------------|
| `id`        | Уникальный идентификатор |
| `name`      | Имя героя |
| `image`     | Изображение |
| `ability`   | Пассивная специальная способность (триггер + эффект) |
| `text`      | Формулировка способности для отображения |

Пример: герой **Бимо** — дополнительный бесплатный добор карты в начале хода (обычный бесплатный добор + ещё один от героя).

Список героев будет добавлен после завершения документации (источник — данные оригинальной игры). Способность героя действует всю партию и учитывается domain-слоем наравне со способностями карт.

## Каталог механик (ключевые слова способностей)

Собран из описаний 504 карт — см. **[MECHANICS.md](./MECHANICS.md)**: триггеры (включая «ПРИЁМ» = флюп), операции, цели, условия и заметные закономерности (ауры строений «на этой линии», счётчики от сброса, состояния земель). Наполняется и уточняется новым OCR.

## Формат колоды

- Колода состоит из **40 карт**.
- **До 4 копий** одной карты. Лимиты копий задаются в **общем конфиге проекта** (по умолчанию — 4 для всех карт; точечные лимиты отдельных карт — переопределением, см. [CONFIG.md](./CONFIG.md)); каталог карт **вшит в игру** и не хранится в базе данных.
- Выбирается **тип земель** и настраивается их **расположение** (порядок типов земель в колоде). Сам порядок на правила не влияет — важен только для механик карт, ссылающихся на порядок / соседство земель.
- **Земли:** ровно **4 тайла**, тип каждого — любой из семи (включая `rainbow`), **дубликаты разрешены**; выбор и порядок — в редакторе колод.
- **Герой привязан к колоде** — колода = 40 карт + 4 тайла земель + герой + раскладка земель.

## Каталог карт

- **Источник контента** — карты **оригинальной настольной игры Card Wars** (наборы и expansions).
- **Исходные данные**:
  - карты — [data/cards_test_v1.json](./data/cards_test_v1.json): **504 карты** из старого OCR. Используется **только поле `description`** и базовые поля (id, название, номер, тип, стоимость, атака/хп, тип земли); поле `mechanics` — черновой автопарсинг v1, **не является источником правды** и будет заменён новым OCR.
  - герои — [data/heroes_original_v1.json](./data/heroes_original_v1.json): 23 героя (имена, тексты способностей; слаги). Реализуемые эффекты героев берутся из этого документа и [RULES.md](./RULES.md) — данные только источник текстов.
- Типы земель в данных: `corn`, `blue`, `good`, `ice`, `sand`, `swamp` + `any` (== `rainbow`, переименовывается конвертером). Тип `special` в данных v1 (5 карт) — это **парные карты** (`companion`, режим 2 на 2).
- Для MVP нужен **базовый набор**: достаточный для интересной партии 1 на 1 (существа, строения, заклинания; разные стоимости и типы земель; несколько Флюпов и пассивов).
- Новый OCR и полный каталог — **после завершения документации**; процесс OCR (формат исходников, разметка связок, QA) будет описан отдельно.
