# AGENTS.md — card_game

Правила для агентов в этом репозитории. Читаются при каждой сессии, поэтому здесь только то, что нужно всегда.

## 1. Сначала скиллы, потом код
1. Выбери подходящие скиллы по таблице в `skills/README.md` и **прочитай `skills/<name>/SKILL.md` до написания кода**.
2. Паттерны не угадывать: если скилл описывает поведение (механики, R3F-доска, миграции, Worker/DO) — следовать ему.
3. Канон скиллов — `skills/` (коммитится). Копии для OpenCode — `.agents/skills/` (локальные, в `.gitignore`). Правка скилла = правка канона + копии.

## 2. Журнал действий — обязательно
Скилл: `docs-journal`. Хелпер: `node scripts/journal.mjs <команда>`.

| Когда | Что делать |
| --- | --- |
| Начало задачи | `node scripts/journal.mjs grep "<ключевые слова>"` и `list 5` — восстановить контекст, сослаться на прошлые записи |
| По ходу | Дописывать решения, числа, находки в открытую запись |
| Конец задачи (в т.ч. провал) | Запись в `docs/journal/<ГГГГ-ММ-ДД>.md`, секция `## ЧЧ:ММ — <заголовок>`: `node scripts/journal.mjs start "<заголовок>"` |

- Папки `docs/` и `docs/journal/` создаёт скрипт — руками не mkdir.
- Крупный разбор (аудит, миграция, дизайн) — отдельный файл `docs/<ТЕМА>.md`, в журнале ссылка и 3–5 выводов с цифрами.
- Прошлые записи не переписывать, только дописывать. Секреты и токены не цитировать.

## 3. Гейт перед коммитом
Порядок из скилла `project-gate`, каждый пункт отдельной командой:

```powershell
npm.cmd test
npm.cmd run test:smoke
npm.cmd run test:store
npm.cmd run test:engine
npx.cmd vite build
npx.cmd tsc --noEmit -p workers/tsconfig.json
npx.cmd eslint <изменённые файлы>
```

- PowerShell: только `npm.cmd` / `npx.cmd`, команды не объединять через `&&`.
- «Exited with code 1» после `vite build` — это warning о размере чанка, сборка проходит.
- Тесты под код не подгонять и не отключать. В отчёте — число прошедших по каждой группе.

## 4. Стиль
- Записи, комментарии и отчёты — по-русски; имена, код и пути — по стилю окружающего кода.
- Сообщать о рисках и найденных багах явно, а не замалчивать; найденное — в журнал.
