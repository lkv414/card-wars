# Объём первой версии (MVP) — выполнено

Все пункты первоначального MVP **реализованы**; документ хранит историю объёма и список того, что осталось.

## Реализовано

| Область | Состояние |
|---------|-----------|
| Режимы | 1v1, FFA на 3–4 игрока, 2v2 «соседи» и «стенка» (общие жизни команды — 40) |
| Лобби | Коды из 4 цифр, готовность, хост (кик, передача, пересадка), скрытые комнаты, режим «любые земли», боты |
| Матч | Мулиган, фазы `draw`/`main`/`combat`, действия, Флюп, парные карты, таймеры хода (90 с), «Поторопить», сдача, переподключение (60 с) |
| Каталог | 853 карты, 74 героя, 44 арта земель; механики v2: 837/853 карт, 25/74 героев |
| Колоды | Редактор, 7 физических типов земель, выбор арта земли, импорт/экспорт по коду v2, выбор героя из галереи |
| Интерфейс | Стиль «войлок и бумага», правая боковая панель HUD, ПКМ — увеличенный просмотр карты, мобильная адаптация, PWA |
| 3D | Квадратный коврик, раскладки под все режимы, анимации по событиям, прогноз боя, жетоны урона и льда |
| Сервер | Cloudflare Worker + Durable Object, Hibernatable WebSockets, alarms, скрытие информации через `viewFor` |
| Качество | 373 теста, CI (lint, typecheck, test, build), смоук-скрипты «двух вкладок» и 2×2 с ботами |

## Осталось

- Способности героев 26–74 — [audits/03-operability.md](./audits/03-operability.md).
- Улучшение ботов (цели для карт и способностей).
- Оптимизация загрузки каталога и сканов — [audits/04-performance.md](./audits/04-performance.md).
- 3D-эмоции, реплеи.
